# RULES

Read this before touching anything.

## Nothing changes without permission

This repo is not yours. Ask first, every time.

- Do not create, edit, delete, rename, or move any file or directory without explicit permission in the current conversation.
- Do not run state-changing git commands (`commit`, `push`, `add`, `rm`, `reset`, `rebase`, `tag`, `branch`) without permission.
- Reading, searching, and read-only commands are always fine.
- Want a change? Propose it: which files, what, why. Then wait.
- Permission for one file is not permission for the repo.

The test: if the working tree or git state changed and the owner did not say yes first, you already failed.
